# TeachifyBD Helper

A small app for TeachifyBD teachers. It sends absence alerts, receipts and results to families from **your own WhatsApp**, on your own computer. Messages wait while it's off and go out when it's back on.

## Download

Get the newest version from **[Releases](https://github.com/dev-adalz/teachify-helper/releases/latest)**:

| Computer | File |
|---|---|
| Windows | `TeachifyBD-Helper-Setup.exe` |
| Mac with Apple chip (M1 or newer) | `TeachifyBD-Helper-arm64.dmg` |
| Mac with Intel chip | `TeachifyBD-Helper-x64.dmg` |
| Linux | `TeachifyBD-Helper.AppImage` (or `.deb` for Ubuntu/Debian) |

## Set up

1. Install and open the helper.
2. On TeachifyBD, go to **Messages → Your WhatsApp** and press **I've installed it, give me a code**.
3. Type the code into the helper, then link your WhatsApp number.

Windows or Mac may warn that the app is from an unknown developer the first time. On Windows choose **More info → Run anyway**; on Mac right-click the app and choose **Open**.

Questions? Message the TeachifyBD team.
